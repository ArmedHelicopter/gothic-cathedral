# 教堂重设计规格 · 典雅大气（English Perpendicular Gothic）

日期：2026-11-27 · 状态：已与需求方逐项确认，待实现

## 0. 设计意图

一句话：**蓝调黄昏里的英式垂直哥特圣殿**。藏青的夜空透过彩窗，象牙白石材撑起星形肋拱顶，黄铜吊灯与淡金细节提供温度；中殿两侧一眼可见十座展台，尽头是独沐金光的未竟之作。

"典雅"来自克制的色彩与精细的垂直线条，"大气"来自三层立面的纵深、贯通地面到拱顶的竖向束柱，以及吊灯沿轴线形成的透视队列。

## 1. 已确认的决定

| 维度 | 决定 |
|---|---|
| 风格 | 英式垂直哥特（Perpendicular）：强竖向、四心圆拱、矩形网格窗格 |
| 配色 | 藏青 + 象牙白 + 淡金（少量点缀） |
| 平面 | 保留中殿轴线与现有外轮廓；改为 拱廊—楼廊—高侧窗 三层立面，侧廊成为真实可见的纵深 |
| 拱顶 | 星形肋拱顶：象牙肋 + 镶金顶饰（boss）+ 藏青拱面点缀金色小星 |
| 光线 | 蓝调黄昏：窗外深藏青天空、冷蓝彩窗光；室内由黄铜吊灯与烛光提供暖光 |
| 陈设 | 黄铜吊灯（每开间一盏、居中悬吊）、管风琴、黑白大理石棋盘地面 |
| 管风琴 | 螺旋楼梯通向的 9.2m 夹层即管风琴楼廊 |
| 展台 | 留在中殿、一眼可见；象牙石台 + 黄铜铭牌 + 地面淡金光池；保留玻璃钟罩 |
| 入场 | 保留蓝图扫描 + 俯冲，惊艳点落在门开后的"点亮"瞬间；总长约 7s，可点击跳过 |
| 保留 | 10 展台 + 中央遮布画作、蓝图扫描入场、螺旋楼梯、单文件零外部资源 |
| 性能 | 中端笔记本（集显/轻薄本）1080p 下 60fps |

## 2. 空间与尺寸

坐标沿用现状：x 横向、z 纵向（+z 为入口南端，−z 为圣所北端），y 向上，单位米。

### 2.1 保持不变
- 外轮廓：`Z_SOUTH = 28.5`、`Z_NORTH = −26.0`、外墙 `WALL_X = ±13.6`
- 中殿墩柱 `PIER_X = ±9.2`，开间 z：`[22.0, 14.5, 7.0, −0.5, −8.0, −15.5, −22.5]`
- 拱顶起拱 `15.6`、拱顶顶点 `24.5`
- 螺旋楼梯：中心 (0, 18)，夹层 `9.2`
- 中央画作：(0, 1.15, −20.5)

### 2.2 三层立面（中殿两侧，每开间）

| 层 | y 范围 | 内容 |
|---|---|---|
| 拱廊 Arcade | 0 – 9.8 | 墩柱柱头降至 **7.2**；开间之间为**四心圆拱**（矢高约为跨度的 0.35，顶点约 9.8）。拱下即侧廊 |
| 楼廊 Triforium | 10.2 – 12.6 | 盲拱窗格嵌板（矩形网格 + 小尖拱头）；底部一条淡金四叶饰饰带作为水平收束 |
| 高侧窗 Clerestory | 12.8 – 15.4 | 每开间一扇宽大的垂直式窗：3–4 根竖棂 + 1 道横档，藏青彩窗 |

- **竖向束柱**：每个墩柱朝中殿一侧加一组细束柱，从地面贯通到 15.6 起拱，直接接住拱顶肋。这条贯通的竖线是"大气"的关键，楼廊饰带、柱头都不得打断它的轮廓。
- **侧廊**：宽 4.4m（9.2 → 13.6），拱顶高约 9.0，使用简单的四分肋拱。外墙每开间一扇垂直式窗，下沿约 2.4。侧廊要被看见，作为纵深层与彩窗光背景，但不放展品。

### 2.3 星形肋拱顶（中殿）
- 每开间：对角肋 + 居间肋（tierceron）+ 枝肋（lierne），在拱面上织出四角星纹样；纵向脊肋贯通全长。
- 主交点与次交点放镶金雕花顶饰（boss），主 boss 直径约 0.7，次 boss 约 0.35。
- 肋为象牙白；肋间拱面为深藏青，带稀疏的程序化金色小星（着色器噪声，非几何）。

### 2.4 地面
- 中殿：黑白大理石棋盘格，0.9m 方格**旋转 45°**；沿中殿两侧（x = ±7.6）各一条 0.25m 藏青镶嵌边带。
- 每座展台下方：直径约 2.2m 的藏青圆环镶嵌，与地面光池同心。
- 侧廊：象牙白石板，矩形错缝铺砌。
- 圣所（z < −17）：抬高一级，白大理石铺面，带淡金细线镶边。

## 3. 陈设

### 3.1 展台（10 座）
- 位置调整为**正对墩柱**：x = ±5.6，z = `[14.5, 7.0, −0.5, −8.0, −15.5]`。展台与墩柱、束柱同轴对齐，吊灯落在两台之间，形成"展台—吊灯—展台"的节奏。
- 形制：象牙石台座，带垂直式线脚（底座 + 嵌板台身 + 檐口）；黄铜铭牌斜置于面向中殿轴线一侧，刻项目名与编号。
- 地面光池：台下一圈淡金加性光晕贴片（不用真实光源），远看一眼可辨。
- 保留玻璃钟罩与现有图标遗物。
- 同步更新 `data.js` 中每个项目的 `bayZ` 与相机预设。

### 3.2 黄铜吊灯
- 4 盏中殿吊灯，挂在开间中点 z = `[10.75, 3.25, −4.25, −11.75]`、y ≈ 8.0（低于楼廊，不遮挡仰视拱顶）。
- 入口开间（z 18.25）在螺旋楼梯正上方，**不放**吊灯。
- 圣所上方 z = −19.0、y ≈ 10.0 挂一盏较小的冠形灯（corona），给画作区域补一点暖色上光。
- 形制：两层环形黄铜架，每层 8–12 支烛臂；用链条挂到拱顶 boss。烛焰使用自发光 billboard，由 bloom 出光晕。

### 3.3 管风琴楼廊
- 9.2m 夹层整体变为管风琴楼廊：前沿是垂直式镂空嵌板栏杆，淡金压顶。
- 琴箱背靠南墙，分左右两塔，夹层中央留开口；锡色管列加镀金管口，顶部带雕花冠饰。
- 管顶不得遮挡南墙玫瑰窗。玫瑰窗与两塔之间的空隙就是从楼廊回望中殿时的取景框。
- 楼廊可经螺旋楼梯步行到达（碰撞体随之更新），作为俯瞰中殿的奖励视角。

## 4. 色板与材质

| 名称 | 色值 | 用途 | 备注 |
|---|---|---|---|
| Ivory Stone | `#E9E1D0` | 墩柱、墙面、立面 | 粗糙度 0.75，轻微纹理 |
| Ivory Rib | `#F2EBDD` | 拱顶肋、窗棂 | 比墙面略亮，突出线条 |
| Navy Web | `#0E1B3D` | 拱顶肋间拱面 | 带金色小星着色器 |
| Navy Glass | `#12306E` | 彩窗主色 | 夹少量宝蓝与淡金碎片 |
| Pale Gold | `#C9A961` | 顶饰、饰带、画框、栏杆压顶 | metalness 1，roughness 0.35 |
| Brass | `#B08D57` | 吊灯、铭牌 | metalness 1，roughness 0.45 |
| Pipe Tin | `#A9ADB3` | 管风琴管 | metalness 1，roughness 0.3 |
| Marble Black | `#111316` | 棋盘格 | roughness 0.25（低，出反射） |
| Marble White | `#ECE9E3` | 棋盘格、圣所 | roughness 0.25 |
| Twilight Sky | `#1A2A5A` → `#0A1230` | 窗外天空 / 环境贴图 | 由地平线向天顶渐变 |
| Candle | `#FFC98A`（≈2700K） | 吊灯烛光 | |

- 原则：淡金只用于**节点**（boss、饰带、压顶、画框、铭牌），绝不大面积使用。
- 石材从冷白改为象牙白，整体的"典雅"主要来自这层暖意。
- 雾 `FogExp2` 改为深藏青偏紫 `#0B1430`，密度保持约 0.0075，以保证远端拱顶可见。

## 5. 光照（中端笔记本预算）

- 动态光源 ≤ 8：月色/天光方向光 1（沿用 keyLight，冷蓝）、半球光 1、画作金色聚光 + 暖补光 2、4 盏吊灯各 1 个 `PointLight`（**不投影**，decay 2，distance 约 12）。
- 冠形灯与展台光池：自发光 + bloom 伪造，不增加真实光源。
- 阴影：只保留现有的静态预烘焙阴影，不新增投影光源。
- 彩窗：沿用冷蓝体积光柱（God rays），改为从高侧窗斜射入中殿。
- 曝光：结束态整体偏暗但拱顶可读；拱顶 boss 与吊灯须是画面中最亮的暖色点。

## 6. 入场序列（约 7s，任意点击/按键跳到结束态）

| 时段 | 时长 | 内容 |
|---|---|---|
| 加载期 | 随实际加载 | 蓝图线框按真实加载进度绘制（保留现状） |
| ① 实体化扫描 | 1.35s | 扫描波自上而下把线框转为石材；**转换光带改为淡金**（线框本身保持冰蓝） |
| ② 俯冲 | 约 2.4s（原 3.0s） | 从楼梯上方俯冲，终点落在中殿入口 z ≈ 12、视高 1.6，沿轴线朝北 |
| ③ 仰望 | 约 1.5s | 镜头缓慢抬头看星形拱顶，FOV 微微放宽；此时室内只有约 15% 的环境亮度，拱顶隐在藏青中 |
| ④ 点亮 | 约 2.5s | 吊灯由近及远逐盏点亮（间隔约 0.35s，每盏带一次短促的 bloom 闪光）；每亮一盏，同开间的高侧窗与拱顶 boss 随之亮起；展台光池淡入；最后画作金色光柱亮起，镜头回落平视画作 |

- ③ 与 ④ 允许重叠约 0.5s，总长控制在约 7s。
- 跳过时立即进入结束态，所有灯为最终亮度，相机在漫游起点。
- 若用户系统开启了 `prefers-reduced-motion`：跳过 ②③，只做 0.6s 的整体渐亮。

## 8. 验收标准

1. `python tools/build_cathedral.py` 生成的单个 `index.html` 可离线打开，无任何外部请求。
2. 中端笔记本 1080p 结束态 ≥ 60fps；draw call 与帧时间相比当前版本增幅不超过 20%。
3. 从入口视角一眼可见全部 10 座展台的光池，铭牌在 6m 内清晰可读。
4. 入场约 7s，任意点击可跳过，跳过后状态与自然播完一致。
5. 仰视时可清晰辨认星形肋纹样和镶金 boss，吊灯不遮挡拱顶主视线。
6. 可从螺旋楼梯走上管风琴楼廊；从楼廊回望时，玫瑰窗不被管列遮挡。
7. 无 NaN / D3D11 着色器回退问题（见 commit 020bb51 的修复，不得回退）。
8. 用 `tools/capture_cathedral_shots.py` 输出入口、仰视、展台、楼廊回望、画作五个机位截图存档。
